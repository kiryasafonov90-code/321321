## Результаты тестов

Фактические цифры пока **не заполняются без реального запуска**. После запуска:

```bash
docker-compose up -d
pytest tests/ui/ -v --alluredir=allure-results
allure serve allure-results
```

В этот файл необходимо внести:
- Passed
- Failed
- Skipped / xfailed (если есть)
- процент успешных
- ссылки/скриншоты Allure
- номера Issues только для реально подтверждённых проблем
