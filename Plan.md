## 2. Инструменты

- **Python 3.11+** — язык автотестов
- **pytest** — фреймворк тестирования
- **Selenium WebDriver** — автоматизация браузера
- **mysql-connector-python** — подключение к БД для проверок
- **Allure** — отчёты
- **Docker / Docker Compose** — окружение (MySQL, gate-simulator, aqa-shop)
- **Faker** — генерация тестовых данных

## 3. Риски

- Изменение вёрстки → Page Object Model со стабильными локаторами
- Flaky-тесты → явные ожидания WebDriverWait
- Недоступность портов → проверка свободности 8080, 9999, 3306
