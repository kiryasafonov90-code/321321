## Связь README с требованиями к сдаче

Требования к репозиторию:
- **Исходное приложение (включая эмулятор платёжного шлюза)** — лежит в папке `app/`.
- **Автотесты на Python** — в папке `tests/`.
- **README.md с инструкцией по запуску** — структура выше закрывает это требование.
- **Отчёт об итогах тестов (Report.md)** — его нужно обновлять после каждого значимого прогона.
- **Отчёт о проведённой автоматизации (Summary.md)** — лучше писать по ходу проекта, а не в конце.
- **Issues с баг-репортами** — заводи их сразу, как только находишь реальные проблемы.
