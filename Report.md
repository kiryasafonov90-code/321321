До фактического прогона дефекты не считаются подтверждёнными.

Для каждого реально упавшего теста создать GitHub Issue с:
1. названием;
2. окружением;
3. шагами воспроизведения;
4. ожидаемым результатом;
5. фактическим результатом;
6. скриншотом;
7. ссылкой на тест и Allure-результат.

## Команда запуска

```bash
docker-compose up -d
pytest tests/ui/ -v --alluredir=allure-results
allure serve allure-results
```
