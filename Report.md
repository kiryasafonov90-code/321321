# Отчёт по итогам тестирования

## Краткое описание

Автоматизировано тестирование веб-сервиса покупки тура (aqa-shop): позитивные и негативные сценарии оплаты по карте и в кредит, а также проверки данных в MySQL.

## Количество тест-кейсов

- Позитивные сценарии: 4
- Негативные сценарии: 15
- Проверки БД: 4
- **Всего: 23**

## Результаты

Фактические значения должны быть заполнены после полного запуска тестов.

| Показатель | Значение |
|---|---:|
| Всего | 23 |
| Успешных | Не запускалось при подготовке документации |
| Неуспешных | Не запускалось при подготовке документации |
| Процент успешных | Не рассчитан |

Команда запуска:

```bash
pytest tests/ui/ -v --alluredir=allure-results
```

## Дефекты

До воспроизводимого прогона дефекты не считаются подтверждёнными.

Предыдущие неподтверждённые утверждения о валидации поля «Владелец», `credit_id` в `order_entity` и ограничении номера карты удалены из отчёта.

Для каждого подтверждённого дефекта следует добавить шаги воспроизведения, ожидаемый и фактический результат, скриншот и ссылку на GitHub Issue.

## Allure

После запуска:

```bash
allure serve allure-results
```

Скриншот Allure следует приложить к итоговой сдаче после фактического прогона.
